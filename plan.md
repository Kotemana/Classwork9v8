# План реализации системы симуляции боев

## Этап 1: Базовая структура классов

### 1.1 Создать класс Fighter (Боец)
**Файл:** `Fighter.cs`

**Поля:**
- `string Name` - имя бойца
- `int MaxHealth` - максимальное здоровье
- `int CurrentHealth` - текущее здоровье
- `int Attack` - атака
- `int Strength` - сила
- `bool IsAlive` - жив ли боец (свойство, проверяет CurrentHealth > 0)

**Конструктор:**
```
Fighter(string name)
- Health = 50 + Random(1, 30)
- Attack = 6 + Random(1, 6)  
- Strength = 1 + Random(0, 4)
- Name = name
```

**Методы:**
- `int CalculateDamage()` - возвращает Random(1, Attack) + Strength
- `void TakeDamage(int damage)` - уменьшает CurrentHealth
- `string GetInfo()` - возвращает информацию о бойце

---

### 1.2 Создать класс Squad (Отряд)
**Файл:** `Squad.cs`

**Поля:**
- `string Name` - название отряда
- `List<Fighter> Fighters` - список бойцов

**Методы:**
- `void AddFighter(Fighter fighter)` - добавить бойца
- `List<Fighter> GetAliveFighters()` - получить живых бойцов
- `Fighter GetRandomAliveFighter()` - получить случайного живого бойца
- `bool HasAliveFighters()` - есть ли живые бойцы
- `string GetReport()` - отчет об отряде

---

### 1.3 Создать класс Faction (Фракция)
**Файл:** `Faction.cs`

**Поля:**
- `string Name` - название фракции
- `List<Squad> Squads` - список отрядов

**Методы:**
- `void AddSquad(Squad squad)` - добавить отряд
- `Squad GetRandomSquad()` - получить случайный отряд
- `Squad GetRandomSquadWithAliveFighters()` - случайный отряд с живыми бойцами
- `string GetFullReport()` - полный отчет о фракции, отрядах и бойцах
- `bool HasSquadsWithAliveFighters()` - есть ли отряды с живыми бойцами

## Этап 2: Инициализация данных

### 2.1 Создать класс Battle (начальная версия)
**Файл:** `Battle.cs`

**Методы инициализации:**

1. `List<string> LoadNamesFromFile(string filePath)`
   - Читает файл names.txt
   - Возвращает список имен

2. `void InitializeFactions(int squadCount, int fightersPerSquad)`
   - Создает 2 фракции (например: "Орки" и "Эльфы")
   - Для каждой фракции создает squadCount отрядов
   - Для каждого отряда создает fightersPerSquad бойцов с рандомными именами
   - Использует цикл по всем фракциям и отрядам (универсально)

3. `void ShowFactionsReport()`
   - Вызывает GetFullReport() для каждой фракции
   - Выводит в консоль

## Этап 3: Боевая система - PvP (1 на 1)

### 3.1 Добавить методы в Battle.cs

**Метод:** `void PvPBattle(Faction faction1, Faction faction2)`

**Логика:**
1. Из faction1 выбрать случайный отряд → случайный боец
2. Из faction2 выбрать случайный отряд → случайный боец
3. Определить, кто атакует первым (рандом или по очереди)
4. Цикл боя:
   - Атакующий наносит урон = CalculateDamage()
   - Защищающийся получает урон через TakeDamage()
   - Вывести: "{атакующий} наносит {урон} урона {защищающемуся}. Осталось HP: {CurrentHealth}"
   - Поменять атакующего и защищающегося местами
   - Продолжать пока один из бойцов не умрет (IsAlive = false)
5. Вывести результат: кто победил, кто проиграл

## Этап 4: Боевая система - Стенка на стенку

### 4.1 Добать метод SquadVsSquad в Battle.cs

**Метод:** `void SquadVsSquad(Squad squad1, Squad squad2)`

**Логика:**
1. Получить списки живых бойцов из обоих отрядов
2. Индексы текущих атакующих: index1 = 0, index2 = 0
3. Цикл боя:
   - Ход бойца из squad1:
     - Взять бойца по index1 (если жив, иначе следующий)
     - Взять цель из squad2 по index2
     - Нанести урон
     - Вывести информацию
     - index1++ (с циклом через % на количество бойцов)
   - Ход бойца из squad2:
     - Взять бойца по index2
     - Взять цель из squad1 по предыдущему индексу (index1-1)
     - Нанести урон
     - Вывести информацию
     - index2++
   - Обновлять списки живых после каждого раунда
   - Продолжать пока в одном из отрядов не закончатся живые
4. Вывести "героев" - живых бойцов отряда-победителя

**Важно:** Мертвые бойцы пропускают ход

## Этап 5: Система классов и способностей

### 5.1 Создать enum FighterClass
**Файл:** `FighterClass.cs`
```
enum FighterClass
{
    Regular,    // Обычный боец
    Berserker,
    Priest,
    Mage,
    Warrior
}
```

### 5.2 Модифицировать класс Fighter

**Добавить поля:**
- `FighterClass Class` - класс бойца
- `int AbilityCooldown` - текущий откат способности
- `bool HasUsedFirstTurn` - для воина (пропустил ли первую атаку)

**Добавить методы:**
- `void UseAbility(...)` - использовать способность класса
- `void ReduceCooldown()` - уменьшить откат на 1

### 5.3 Создать класс FighterAbilities
**Файл:** `FighterAbilities.cs`

**Статические методы для каждой способности:**

1. `BerserkerAbility(Fighter attacker, List<Fighter> enemies)`
   - Проверить есть ли враг с HP < 10
   - Если есть - выполнить второй удар по случайному такому врагу

2. `PriestAbility(Fighter priest, List<Fighter> allies)`
   - Проверить откат (если > 0, пропустить)
   - Найти союзника с HP < 20 и минимальным HP
   - Вылечить на определенное количество HP
   - Установить откат = 3

3. `MageAbility(Fighter mage, List<Fighter> enemies, bool useFireball)`
   - Если не файрбол: атаковать врага с минимальным HP
   - Если файрбол и откат = 0:
     - Выбрать 3 целей (текущая, до, после по кругу)
     - Нанести урон всем
     - Установить откат = 3

4. `WarriorAbility(Fighter warrior)`
   - Проверить HasUsedFirstTurn
   - Если false: пропустить ход, установить true
   - Если true: обычная атака

## Этап 7: Битвы между фракциями

### 7.1 Добавить метод FactionWar в Battle.cs

**Метод:** `void FactionWar(Faction faction1, Faction faction2)`

**Логика:**
1. Взять первый отряд faction1 и первый отряд faction2
2. Провести SquadVsSquad
3. Определить победивший отряд
4. Проигравшая фракция выставляет следующий отряд
5. Победивший отряд (недобитый) дерется с новым отрядом
6. Продолжать пока у одной из фракций не закончатся отряды
7. Объявить победившую фракцию

---

## Этап 8: Главная программа

### 8.1 Модифицировать Program.cs

**Структура:**
```
1. Запросить у пользователя:
   - Количество отрядов во фракции
   - Базовое количество бойцов в отряде

2. Создать объект Battle

3. Инициализировать фракции (LoadNames + InitializeFactions)

4. Показать отчеты по фракциям

5. Меню выбора типа боя:
   - 1: PvP (1 на 1)
   - 2: Стенка на стенку
   - 3: Война фракций
   - 0: Выход

6. В зависимости от выбора запустить соответствующий бой
```
